# Formulario de Asistencia

Formulario web sencillo para registrar asistencia con nombre, fecha y hora. Genera un archivo CSV descargable.

## Características

- HTML, CSS y JavaScript puro (vanilla)
- Validación básica del nombre
- Guarda temporalmente en `localStorage`
- Tabla con lista de asistentes
- Descarga directa de `asistencia-YYYY-MM-DD.csv`
- Diseño responsive

## Uso local

1. Clonar este repositorio
2. Abrir `index.html` en cualquier navegador moderno
3. Escribir nombre completo y pulsar **Marcar asistencia**
4. Pulsar **Descargar CSV** para obtener el archivo
